# SIGOM — Fase 12.12

## Portfólio selecionado por padrão

Após a autenticação e o carregamento dos dados do Supabase, o Dashboard inicia com a opção **Somente portfólio selecionado (Planilha do Portfólio)** marcada quando `portfolio_obras` possui registros.

O usuário pode desmarcar a opção a qualquer momento para retornar à base principal de Obras.

Se o Portfólio estiver vazio, o sistema mantém automaticamente a Planilha de Obras como fonte ativa.
