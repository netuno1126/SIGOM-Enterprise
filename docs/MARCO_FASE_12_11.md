# Fase 12.11 — Percentuais com escala e formatação corrigidas

- Corrige a leitura de percentuais com ponto decimal, como `93.77`.
- Impede que `93.77` seja interpretado como `9377`.
- Exibe `% medido`, `% estimado`, `% empenhado` e medições com duas casas decimais.
- Normaliza dados legados evidentemente multiplicados por 100.
- Mantém o IDP oficial como `% medido / % estimado`.
