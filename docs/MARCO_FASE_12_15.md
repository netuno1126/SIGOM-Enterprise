# Fase 12.15 — Média Mensal Global contextual e abreviada

- O KPI da Média Mensal Global usa abreviações monetárias pt-BR: mil, Mi, Bi, Tri, Qua e Qi.
- O valor completo permanece disponível no tooltip do cartão.
- A aba calcula o conjunto do grupo selecionado, do Portfólio selecionado ou da base geral.
- Quando grupo e Portfólio estiverem ativos, o grupo é calculado sobre os registros do Portfólio.
- Nenhuma migration SQL é necessária.
